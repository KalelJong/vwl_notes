\section{Stille Reserven}
Unternehmen schliesst Bilanzkonten intern, alle tatsächlichen ökonomischen Ereignissen. 
\begin{itemize}
    \item Intern (True, Fair View, Accounting Standards Konvention, keine Stille Reserven nicht erlaubt)
    \item Extern (Nach OR, stille Reserven unterschiedlich zu Intern)
\end{itemize}                                                        

\subsection{Bildung stiller Reserven}
\begin{itemize}
    \item Entweder unterbewertung von Aktiven
    \item Oder Überbewertung Passiven
    \item Ziel, z.B. durch schlechtere Gewinnstellung kann Unternehmen weniger gewinnsteuer zahlen 
\end{itemize}
