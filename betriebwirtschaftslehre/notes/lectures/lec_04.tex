\subsection{Taylorismus}
\begin{itemize}
    \item Ab 1900-1945
    \item Gilt als Begründer Managementforschung
    \item \textbf{Ziel}: Annäherung der menschlichen Arbeit an Effizienz und Genauigkeit von Maschinen
    \item Gedanke: Wissenschaftliche Angehensweise im Unternehmen 
    \begin{itemize}
        \item Messung von Zeit pro elementare Aufgabe
        \item Trennung Arbeitsvorbereitung und Durchführung (Nicht mehr arbeiter bestimmen ihre Arbeitsabfolge, sondern Spezialisten)
        \item Kontrolle durch Managementsschicht
        \item Optimierung von Bewegung und Platzierung von Maschinen 
        \item Einführung Leistungslohn 
    \end{itemize}
    \item Strenge Zeitkontrollen für gesteigerte Produktivität
    \item Ansatz erfuhr Widerstand durch die Arbeiterschaft, die wie Maschinen behandelt wurden.
    \item Basis der Substitution von aus der Arbeiterschaft organisch entstehenden Führungskräften durch professionelle Manager/Aufseher
  
\end{itemize}

\subsubsection{Kritische Würdigung}
\begin{itemize}
   \item Kritische Würdigung
    \begin{itemize}
        \item Strenge Teilung der Arbeit innerhalb des Unternehmens führe zu Dequalifizierung\footnote{durch strenge spezialisierung in einer Aufgabe, dies trägt zur Ersetzbarkeit der Arbeiter bei.} und
        \item Fremdbestimmung und Isolation, da interpersönliche Interaktionen als Ineffizient gelten
        \item Menschenbild: Faule und genusssüchtige Menschen
        \item Reflexion: Gilt die Digitale Revolution und KI als Re-Taylorisierung der Arbeit? \footnote{z.B. Eingebaute digitale KI-Aufseher in Unternehmenscomputer mit Warnungen, falls die Arbeit unterbrochen wurde}
    \end{itemize}
\end{itemize}
\subsection{Bürokratietheorie Max Weber}
\begin{itemize}
\item historischer Kontext:
    \begin{itemize}
        \item Es fanden zu jener Zeit Versuche das gesellschaftliche Weltbild und Arbeitswelt zu rationalisieren
        \item Zunahme der Verwaltungsapparate in Unternehmen und Staat
    \end{itemize} 
    \item Ziel: war die Entwicklung einer Theorie der \textit{rationalen} Herrschaft.
    \item \textbf{Idealtypus}: Bürokratie
    \item Methodik
    \begin{itemize}
        \item Idealkonstrukt (Bürokratie) diene zum Abgleich und Orientierung der Realität und Praxis
    \end{itemize}
\end{itemize}
\subsubsection{Die 7 Merkmale}
\begin{enumerate}
    \item Regelgebundenheit der Amtsführung
    \item Spezialisierung und klare Abgrezung von Kompetenzbereichen
    \item Prizip der Amtshierarchie (klare Dienstwege und Authorität)
    \item Aktenmässigkeit der Verwaltung (Protokollierung)
    \item Unpersönlichkeit der Amtsführung \footnote{In einem Klaren gegensatz zur Feudalen Herrschaft}
    \item Definierte Qualifikationen für Stelleninhaber
    \item Fixierte Laufbahn und Aufstiegsmöglichkeiten (inkl Gehaltshierarchie) \footnote{Zu den Merkmalen wurden die hinterstehenden Überlegungen nicht erläutert }
\end{enumerate}
\subsubsection{Kritische Würdigung}
\begin{itemize}
    \item Gründer der Organisationsforschung
    \item Grundlagen wirken bis heute in Unternehmen und Behörden nach
    \item Verkannte aber Probleme wie Motivationsverslust, Ineffizienz, Inflexibilität von Bürokratien
\end{itemize}
\subsection{Human-Relations-Ansatz}
\begin{itemize}
    \item Ab 1930
    \item historischer Kontext
    \begin{itemize}
        \item Verschlechtende Arbeitsbedingungen und Stärkung von Arbeiterbewegungen
        \item Taylorisierung der Arbeit war eine der Quellen der Unzufriedenheit
    \end{itemize}
    \item Startpunkt: Empirische Forschung von Einfluss physische Faktoren auf Produktivität (licht, Temperatur, Lärm) \footnote{Methodik des Taylorismus}
    \item Aus Studie wurde beobachtet:
    \begin{itemize}
        \item psychische und soziale Faktoren trugen mehr zur Produktivitätssteigerung bei als optimale physische Faktoren. 
    \end{itemize}
    \item Schlussfolgerung
    \begin{itemize}
        \item Hinwendung zu Faktoren: Fürhungsstil, Entlöhnung etc. 
    \end{itemize}
\end{itemize}

\subsubsection{Kernmerkmale}
\begin{itemize}
    \item In gegensatz zum Taylorismus in der Methode
    \begin{itemize}
        \item Soziale Beziehungen und freundliche Fürhung in Arbeitsumfeld als \textbf{Hauptquelle von Produktivität}
    \end{itemize}
    \item Führungskraft muss von Rolle des „Aufpassers“ und Planers in Rolle
des Vermittlers bzw. Beschäftigten und höherem Management wechseln
\end{itemize}

\subsubsection{Kritische Würdigung}

\begin{itemize}
    \item Umstrittene Wissenschafttliche Sauberkeit der Methode
    \item Vernachlässigt umfangreichere soziale Strukturen und organisationalen Rahmen
    \item Stark auf mikro-ebene fokussiert
\end{itemize}
\pagebreak
\subsection{Neo-Institutionalismus}
\begin{itemize}
    \item Ab 1970er Jahre
    \item Kontext
    \begin{itemize}
        \item Skepsis gegenüber Annahme, dass die Grundursache für Wandel von Organisationen/Untehmen das Streben nach Effizienz war
    \end{itemize}
    \item Definition
    \begin{itemize}
        \item  Institution = soziale Konventionen (Regeln, Erwartungen), die nicht hinterfragt werden und als \textit{objektiv gegeben} betrachtet werden
    \end{itemize} 
\end{itemize}
\subsubsection{Kernmerkmale}
\begin{itemize}
    \item Grundannahme
    \begin{itemize}
        \item Manager richten sich bewusst/unbewusst nach diesen Erwartungen aus.  
    \end{itemize}
    \item \textit{Isomorphie}: Organisationen tendieren dadurch zur Ähnlichkeit 
    \item Konformität mit jenen Erwartungen, erhöhen die überlebenschancen von Organisationen.
\end{itemize}

\subsubsection{Kritische Würdigung}
\begin{itemize}
    \item Hinterfragen im Hintergrund, weil Ansatz von bestehenden sozialen Erwartungen orientiert ist
    \item Ist hauptsächlich Deskriptiv $\rightarrow$ nicht verändernd/transformativ 
    \item Gefahr des Ansatzes ist eine zu starke Trennung von Formalstruktur und Praxis \footnote{In Folien wurde das Beispiel FIFAs erwähnt, die rein Formal betrachtet die sozialen Konvenktionen und Erwartungen folgt, aber in der Praxis zahlreiche korruptions Skandale aufweist} 
\end{itemize}
\subsection{Fazit und Reflexion}
Jede der Strömungen betrachtet das Managementwesen aus einer anderen Perspektive, die sich zum Teil ergänzen und widersprechen. \textbf{Es gibt keine Universal-Theorie.} Sie gelten als Scheiwerfer und Werkzeuge die Verschiedene Aspekte beleuchten und je nach  
Umstand kombiniert werden können.
